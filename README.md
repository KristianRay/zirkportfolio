# Zirk — Web3 Portfolio

Personal portfolio website for **Zirk**, a Web3 Community Moderator and Collaboration Manager with 1+ year of experience building Discord communities, managing 100+ partnerships, and securing 2,500+ whitelist spots.

🔗 **Live:** [zirkportfolio.vercel.app](https://zirkportfolio.vercel.app)

---

## Sections

| Section | Description |
|---------|-------------|
| About | Introduction and background as a Web3 professional |
| Skills | Community Moderation, Collab Management, and Graphic Design |
| Experience | Grid of 12 Web3 projects worked on with roles |
| Works & Designs | Auto-scrolling carousel of graphic design works |
| Reviews & Feedback | Screenshots of feedback and reviews from the community |
| Contact | Email button and Calendly scheduling link |

---

## Features

- Animated entrance and scroll animations via GSAP + ScrollTrigger
- Auto-scrolling infinite carousel (forward + reverse rows) for design works
- Lightbox modal for viewing carousel images fullscreen
- Calendly popup widget for scheduling calls
- Responsive design — desktop, tablet, and mobile
- SEO optimized — meta description, keywords, canonical, Open Graph, Twitter Card, JSON-LD structured data
- Security best practices — `rel="noopener noreferrer"` on all external links

---

## Tech Stack

- HTML, CSS, JavaScript
- [GSAP](https://gsap.com/) + ScrollTrigger for animations
- [Calendly Widget](https://calendly.com/) for scheduling
- Deployed on [Vercel](https://vercel.com/)
